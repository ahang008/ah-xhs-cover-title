# 使用方法与案例

## 触发方式

- 指令触发：`/ah-xhs-cover-title`
- 自然语言触发：「帮我生成封面」「短视频标题和封面」「给我出几个标题」

## 输入方式

用户可以输入以下任意形式：

1. **完整文章/脚本**（最推荐）
   直接贴文案，让 AI 从中提取核心观点和素材

2. **选题/主题词**
   如"想赚钱先离职"、"普通人如何布局2026"
   AI 会根据关键词路由到对应赛道

3. **一段核心观点**
   如"讨厌工作不是问题，把它当跳板才是解法"

4. **已有标题（要求优化）**
   AI 会识别当前标题用了什么钩子，给出同赛道的其他方案

```

- 内容赛道：[主赛道] + [副赛道]
- 匹配钩子：[钩子1]、[钩子2]、[钩子3]
- 核心观点提取：[一句话]

---

### 1-2

- 标题：[标题]
- 封面：[三行]
- 理由：[为什么这条最好]

**推荐2**：...
**推荐3**：...
```

## 质量检查清单

生成每条方案后，AI 自检：

| 检查项 | 标准 |
|---|---|
| 标题长度 | 15-30字，不超过35字 |
| 封面第一行 | 2-8字，做视觉锚点 |
| 封面第二行 | 4-10字，承接或制造张力 |
| 封面第三行 | 3-8字，落点或反转 |
| 封面总字数 | 三行合计不超过25字 |
| 标题和封面关系 | 封面是标题的"视觉翻译"，不是复制粘贴 |
| 钩子可追溯 | 每条都能对应到具体钩子代号 |
| 口播友好 | 标题念出来顺口，不拗口 |

---

## 说话风格

1. 直接给方案，不废话
2. 路由结果先行，让用户知道"为什么选这个"
3. 每条方案都有追溯，不是凭空编的
4. Top 3 推荐理由要具体，不说"这条不错"这种废话

**绝对不做的事：**
- 不生成没有钩子追溯的标题
- 不生成超过25字的封面三行
- 不把标题直接复制到封面上
- 不生成书面语、不口播友好的标题

## 使用案例

**案例：用户输入一篇《想赚钱先离职》的文案**

AI 识别：
- 赛道：5职场生存（主）+ 1搞钱赚钱（副）
- 钩子：C反常识对比、G情绪钩子、B顿悟发现
- 素材：工地安全员转型故事、兄弟月薪4千到五位数

生成方案（部分）：

> 方案一：C反常识对比 x 对比撕裂型
> 1-1
> 标题：在工地上亏的是命，自己折腾亏的是钱
> 第一行：打工亏的是命
> 第二行：折腾亏的是钱
> 第三行：性质完全不同
> 追溯：C + 1搞钱赚钱，参考案例库 #071

> 推荐1：2-1
> 标题：讨厌工作的人，你的人生反而要起飞了
> 封面：讨厌工作的 / 恭喜你 / 要起飞了
> 理由：情绪钩子精准命中目标人群，"恭喜你"制造反差悬念，三行极简有冲击力
