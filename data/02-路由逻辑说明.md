# 路由逻辑说明

路由 = 用户丢一篇文章进来，AI 自动判断：用什么钩子手法 + 选什么赛道 + 封面三行怎么拆。
路由的目的是让生成结果可解释、可追溯，不是随机输出。

---

## 路由三层决策

### 第一层：识别内容赛道

扫描用户输入的关键词，匹配6条赛道。

| 代号 | 赛道 | 识别关键词 |
|---|---|---|
| 1 | 搞钱赚钱 | 赚钱、财富自由、搞钱、生意、卖更贵、赚钱逻辑、副业、变现 |
| 2 | 自我成长 | 执行力、成长速度、看书、状态洁癖、背叛自己、学习、进步、改变 |
| 3 | 趋势洞察 | 经济下行、2026、未来五年、黄金赛道、出路、风口、趋势、布局 |
| 4 | 人际关系 | 熟人、恶意、隐私、社会化、面子、社交、人脉、信任 |
| 5 | 职场生存 | 不上班、自由职业、职场潜规则、摆摊、副业、离职、创业 |
| 6 | 心态情绪 | 焦虑、低谷、内耗、匪气、自信、勇气、不体面、坚持 |

**规则：**
- 可以有主赛道 + 副赛道（最多2条）
- 以出现关键词最多的赛道为主赛道
- 副赛道用于补充方向，不单独生成

---

### 第二层：匹配钩子手法

根据内容特征，从8种钩子中选出最适合的2-3种。

| 内容特征 | 优先匹配钩子 |
|---|---|
| 有明确的反常识观点 | C反常识对比 |
| 有具体数字/数据（N个/N步/N万/N年） | F数字锚点 |
| 有"我发现/我悟到/突然发现"的个人洞察 | B顿悟发现 |
| 有明确的目标人群（25-35岁/普通人/打工人） | E身份圈定 |
| 有"建议/千万不要/尽早/尽量"等建议语气 | A建议祈使 |
| 有具体方法/步骤/怎么做到 | D如何方法 |
| 有情绪痛点（焦虑/低谷/讨厌/害怕/内耗） | G情绪钩子 |
| 借势热点人物/事件/年份节点 | H热点嫁接 |

**规则：**
- 优先匹配 2 种钩子，最多不超过 3 种
- 选钩子时看内容"是什么类型的句子"，不是看话题方向
- 同一篇文章可能同时匹配多个钩子，每种钩子各生成2-3条

---

### 第三层：锁定拆法

根据匹配到的钩子，自动选择封面三行拆法。

| 钩子 | 适配拆法 |
|---|---|
| B顿悟发现 | 结论前置型 |
| D如何方法 | 结论前置型 / 递进悬念型 |
| F数字锚点 | 结论前置型 |
| H热点嫁接 | 结论前置型 |
| E身份圈定 | 递进悬念型 |
| G情绪钩子 | 递进悬念型 |
| A建议祈使 | 祈使直给型 |
| C反常识对比 | 对比撕裂型 |

**规则：**
- 一个钩子对应一种拆法，在生成时直接套用
- 详见 `data/01-封面三行拆法详解.md`

---

## 提取核心素材

在路由之前，需要从用户输入中提取可用素材：

1. **核心观点是什么**（一句话概括）
2. **目标人群是谁**（谁会看）
3. **可用素材**：数据、故事、金句、反差点

素材越丰富，生成的标题冲击力越强。

---

## 用户反馈迭代规则

| 用户反馈 | AI 操作 |
|---|---|
| "再来几条" | 用剩余未使用的钩子手法补充生成 |
| "风格再激进一点" | 切换到 C反常识对比 或 G情绪钩子 |
| "太夸张了" | 切换到 D如何方法 或 A建议祈使 |
| "换个方向" | 切换赛道重新路由 |
| "这个标题更好" | 记录偏好，下次优先用该钩子 |

---

## 追溯规则

每条生成的方案必须包含：
- 钩子代号（如 C反常识对比）
- 赛道代号（如 5职场生存）
- 参考案例编号（如 #012）

追溯格式：`追溯：C + 5职场生存，参考案例库 #012`

无追溯的方案视为不合格，不输出。
