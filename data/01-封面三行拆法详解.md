# 封面三行拆法详解

封面三行 = 视频封面从上到下排列的三行大字。
三行不是随意写的，有固定拆法规律，共4种。

---

## 拆法一：结论前置型（最常用，约40%）

**结构：**
- 第一行：核心概念/标签词（2-6字，做视觉锚点）
- 第二行：展开/补充（承接第一行）
- 第三行：落点/结论（给出结果或悬念）

**本质：** 先给结论或概念，吸引用户停下来细看。

**典型案例：**
- 搞钱书单 / 读完这6本 / 2026就稳了
- 突然发现 / 会赚钱的人会 / 持续不断地赚钱
- 底层突围 / 死磕3件事情 / 2026改变人生
- 转运科学 / 3步学会 / 运气操纵术

**适配钩子：** B顿悟发现、D如何方法、F数字锚点、H热点嫁接

---

## 拆法二：递进悬念型（约25%）

**结构：**
- 第一行：设定场景/身份（圈人，让目标人群觉得说的是自己）
- 第二行：制造张力（矛盾/反差，制造悬念）
- 第三行：给出反转或留悬念（给出答案或继续吊胃口）

**本质：** 用悬念制造好奇心，驱动用户点击。

**典型案例：**
- 为什么高敏感人 / 看透一切 / 却总不成事
- 30-35岁女生 / 如何提前应对 / 中年返贫
- 没有父母托举的 / 普通女生 / 选择城市 等于二次投胎
- 突然悟了 / 低谷期其实 / 是件好事

**适配钩子：** E身份圈定、G情绪钩子

---

## 拆法三：祈使直给型（约20%）

**结构：**
- 第一行：强烈建议/千万不要/尽早...（祈使动词开头，制造紧迫感）
- 第二行：具体行为（做什么/不做什么）
- 第三行：行为对象或后果

**本质：** 直接下命令，用户被"指挥"后产生行动冲动。

**典型案例：**
- 强烈建议 / 不要让任何人 / 知道你的动态
- 千万不要 / 一边做 / 一边怀疑
- 建议所有普通女孩 / 大城市再难混 / 也别回老家
- 真心建议大家 / 尽早用「无人兜底」/ 的态度过一生

**适配钩子：** A建议祈使

---

## 拆法四：对比撕裂型（约15%）

**结构：**
- 第一行：A面（常识/表象，大多数人认同的观点）
- 第二行：转折词（其实/而不是/代替不了）
- 第三行：B面（反转/真相，打破常识的结论）

**本质：** 用"常识 vs 真相"的撕裂感制造冲击力，让用户产生认知失调后点击。

**典型案例：**
- 成长最快的方式 / 是研究赚钱 / 而不是坚持学习
- 早慧 / 代替不了 / 阅历
- 入世赚钱 / 其实就是 / 最好的修行
- 打工亏的是命 / 折腾亏的是钱 / 性质完全不同

**适配钩子：** C反常识对比

---

## 拆法选择决策表

| 内容特征 | 优先拆法 |
|---|---|
| 有"我发现/突然悟了"等洞察 | 结论前置型 |
| 有具体数字/N个/N步/N年 | 结论前置型 |
| 有"建议/千万不要/尽早" | 祈使直给型 |
| 有反常识观点/X其实Y/X代替不了Y | 对比撕裂型 |
| 有明确目标人群（25-35岁/普通人/打工人） | 递进悬念型 |
| 有情绪痛点（焦虑/低谷/讨厌/害怕） | 递进悬念型 |
| 借势热点人物/事件/年份 | 结论前置型 |
