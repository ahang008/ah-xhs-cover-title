# ah-xhs-cover-title

短视频封面标题生成器。输入文章或选题，自动识别内容赛道、匹配钩子手法，生成标题和封面三行文案。

**核心能力：** 从 85 条验证过的爆款公式中做路由匹配，每条输出都能追溯到具体的钩子手法和案例编号。

---

## 特性

- **双层分类体系**：8 种钩子手法（怎么写）+ 6 条内容赛道（写什么）
- **可追溯生成**：每条方案都对应具体案例编号，不是凭空编造
- **4 种封面三行拆法**：结论前置型、递进悬念型、祈使直给型、对比撕裂型
- **用户反馈迭代**：支持"再来几条""换个方向"等指令
- **即开即用**：无需训练，直接通过 Claude Code 触发

---

## 快速开始

### 触发方式

```
/ah-xhs-cover-title
```

或自然语言：

- 「帮我生成封面」
- 「短视频标题和封面」
- 「给我出几个标题」

### 输入方式

1. **完整文章**（最推荐）
2. **选题/主题词**，如「想赚钱先离职」
3. **一段核心观点**，如「讨厌工作，把它当跳板才是解法」
4. **已有标题**（要求优化）

## 质量标准

生成每条方案后自检：

| 检查项 | 标准 |
|---|---|
| 标题长度 | 15-30字，不超过35字 |
| 封面三行合计 | 不超过25字 |
| 标题和封面关系 | 封面是标题的视觉翻译，不是复制 |
| 钩子可追溯 | 每条对应具体钩子代号 + 案例编号 |
| 口播友好 | 标题念出来顺口，不拗口 |

---

## 用户反馈迭代

| 反馈 | 处理 |
|---|---|
| 再来几条 | 用剩余未使用的钩子手法补充生成 |
| 风格再激进一点 | 切换到 C 反常识对比或 G 情绪钩子 |
| 太夸张了 | 切换到 D 如何方法或 A 建议祈使 |
| 换个方向 | 切换赛道重新路由 |
